# Food Business Operations Notes

Software cannot rescue poor route density or inconsistent food.

## Pilot structure
- launch in one geographic cluster
- target 2 hostels + 2 offices or an equivalent dense set
- 20–50 paid meals/day is enough to learn
- two main menu choices per period is operationally healthier than a restaurant-sized menu

## Metrics to collect
- food cost per delivered box
- packaging cost
- delivery cost per box and per hub
- on-time percentage
- repeat order rate
- skip/switch rate
- rating by recipe
- complaints per 100 meals
- hub meals/drop
- prepared vs delivered waste proxy
- outstanding wallet credit liability

## Box labels
Include order code, short customer identifier, meal, variant, hub, period and QR/order reference. Avoid unnecessary personal information.

## Reusable boxes
Do not make reusable steel containers a launch dependency. Add a return/deposit workflow only after route regularity is proven.
