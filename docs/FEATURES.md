# Feature Map

## Public acquisition

- homepage explains the flexible-credit problem in under 10 seconds
- menu preview and upcoming slots
- credit plans
- delivery hubs
- hostel partnership pitch
- corporate subsidy/payment models
- FAQ and pilot contact

## Customer portal

### Today
Select available menu slot + hub and submit through atomic order creation.

### Planner
Week view for Lunch / Dinner / Skip. Production cutoff remains server-authoritative.

### Wallet
Current balance, plans and ledger explanation. Purchases route to payment submission.

### Orders
Order/date/period/meal/hub/status history.

### Hubs
Active pickup points and default hub selection surface.

### Payments
Manual proof/reference upload. Pending payments create no credits until approved.

### Referrals
Customer code and backend qualification concept. Reward only after a paid qualifying order.

### Profile
Name/mobile/defaults such as spice preference. Keep customization constrained to options the kitchen supports.

### Support
Order-specific issue workflow + WhatsApp fast path.

## Admin portal

- daily KPI dashboard
- order search/filter/export surface
- meal catalogue CRUD
- date/period menu calendar
- aggregated kitchen totals
- customers and notes
- payment verification
- wallet ledger/controlled adjustment
- hubs and capacity
- delivery runs
- feedback quality dashboard
- reports/KPIs
- staff role visibility
- system cutoffs/policies

## Partner portal

- today's hub counts/ETA
- hub profile and temporary-change request
- minimal collection list
- invoices/commission/subsidy area
- operational support escalation
